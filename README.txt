CV Master Builder - PWA Mobile + PDF Fixed Version

What is fixed:
1. PDF download now exports only the CV template, not the whole page.
2. If the PDF library fails to load, the system opens Print so the user can choose Save as PDF.
3. Mobile view improved for phones and tablets.
4. PWA support added: manifest, service worker, app icons and Install App button.
5. Works as a static website on GitHub Pages.

How to use:
- Upload all files to GitHub Pages.
- Open index.html.
- On supported browsers, click Install App to add it as an app.
- Use Download PDF CV to export the CV only.

Important:
- For the Install App button to appear automatically, the site must be served through HTTPS, for example GitHub Pages.
- Static website data is saved in browser localStorage. Use Export JSON to save data manually.
